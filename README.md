# Image Privacy Cleaner — Windows GUI (review branch)

画像をローカルで開き、マウスで指定した領域を黒塗りし、EXIF/GPS/ICCなどの対応メタデータを取り除いて**新規コピー**に保存します。

**操作:** 画像を追加 → 画像ごとにプレビューで範囲指定 → 検査 → 新しいPNGを保存 → 生成画像を目視確認。

- 画像別の黒塗り領域は混同しません。
- 全画像に同じ数値座標で黒塗りする高度設定は通常画面では隠し、複数画像に適用する場合には確認を求めます。
- 原本が保存中に変更されれば新しい出力を破棄します。既存ファイルは上書きしません。
- OCR文字認識、顔認識、QRコード自動検出、動画/複数フレームの確実な匿名化は**未実装**です。画像に個人情報が残っていないことは保証しません。
- 実機DPI、透明度、JPEG圧縮、各画像形式での再確認が必要です。

実行: `python windows_app.py`。テスト: `python -m unittest discover -s tests -p 'test_*.py' -v`。
**Store提出HOLD:** Windows GUI、MSIX、WACK、ライセンス/素材権利、Store審査は未合格。
